# AppRelocator 사용 안내

AI 앱·개발 도구의 프로그램과 데이터를 C: 에서 원하는 드라이브로 옮겨 C: 공간을 확보하는 Windows 앱 **AppRelocator** 의 사용 안내입니다.

## 다운로드 (Windows 10·11 x64, 무료)

| 파일 | 설명 |
|---|---|
| [AppRelocator-Setup.exe](https://github.com/sysmetrix/app-relocator-guide/releases/latest/download/AppRelocator-Setup.exe) | 설치 프로그램 (관리자 권한 불필요) |
| [AppRelocator-Portable.exe](https://github.com/sysmetrix/app-relocator-guide/releases/latest/download/AppRelocator-Portable.exe) | 포터블: 설치 없이 바로 실행하는 파일 하나 |
| [AppRelocator-win-x64.zip](https://github.com/sysmetrix/app-relocator-guide/releases/latest/download/AppRelocator-win-x64.zip) | 포터블 + 명령줄 도구 + 안내 문서 |

링크는 늘 최신 버전을 받습니다. 지난 버전과 SHA-256 은 [릴리스](https://github.com/sysmetrix/app-relocator-guide/releases)에 있습니다. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 › 실행**을 누르세요(아직 코드 서명이 없음).
