# AppRelocator 사용 안내

Codex · Claude · Gemini 가 C: 에 쌓아 둔 데이터를 원하는 드라이브로 옮겨 C: 공간을 확보하는 Windows 앱 **AppRelocator** 의 사용 안내입니다.

- **절차 지도 (웹)**: https://sysmetrix.github.io/app-relocator-guide/
- **작동 원리 (웹)**: https://sysmetrix.github.io/app-relocator-guide/how-it-works.html
- [사용 절차 체크리스트](실행-절차서.md)
- [외장 드라이브 하나를 여러 PC 에서 쓰기](여러-PC에서-쓰기.md)

웹의 절차 지도는 일반 안내입니다. PC 마다 실제 용량과 주의할 점이 들어간 지도는 AppRelocator 를 설치한 뒤 시작 메뉴의 **AppRelocator 사용 절차**로 여세요.

이 저장소는 안내 문서와 설치 파일(릴리스)을 담고 있습니다. 프로그램 코드는 별도 저장소에 있습니다.
