01 · 고르기

옮길 곳은 직접 고릅니다

C: 가 아닌 NTFS 드라이브면 내장이든 USB 든 됩니다. 눌러서 바꿔 보세요 — 아래 장면들이 고른 드라이브로 바뀝니다.

02 · 옮기기

복사하고, 확인하고, 연결을 남깁니다

원본은 지우지 않고 '이전 사본'으로 둔 채, 파일 수와 크기가 맞을 때만 원래 자리에 연결을 만듭니다.

03 · 실행

앱은 예전 경로를 열고, Windows 가 이어 줍니다

원래 자리에 남은 '연결'(디렉터리 정션)은 용량이 0 이고, 여는 순간 대상 드라이브의 실제 폴더로 이어집니다. 드라이브 문자가 바뀌어도 볼륨 ID 로 찾아갑니다.

앱 안에서는 아무것도 바뀌지 않습니다 — 따로 설정할 것이 없습니다.

04 · 업데이트

새 버전도 대상 드라이브에 쌓입니다

업데이트 프로그램은 원래 경로에 새 버전을 쓰고, 연결을 따라 대상 드라이브에 저장됩니다. 드물게 폴더를 통째로 바꾸는 업데이트가 연결을 깨면, 진단·복구가 찾아 다시 연결합니다.

05 · 앱별

앱마다 가장 안전한 방법으로

스토어 앱은 Windows 공식 기능으로, 설치형 앱은 연결로, 설치 위치를 고를 수 없는 브라우저는 설치한 뒤 프로그램 폴더째 옮깁니다.

06 · 효과

옮길 앱을 골라 보세요

단, 옮긴 직후에는 원본이 '이전 사본'으로 남아 있어 C: 가 바로 비지 않습니다. 앱이 잘 되는지 확인하고 지워야 공간이 생깁니다.
